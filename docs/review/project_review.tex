\section{Abstract}
HireSight represents a paradigm shift in AI-assisted recruitment, providing a comprehensive intelligence layer for both candidates and recruiters. The project is defined by five major technological pillars:
\begin{itemize}
    \item \textbf{AI-Driven Talent Orchestration:} A unified ecosystem that replaces fragmented manual hiring workflows with a high-performance, automated pipeline.
    \item \textbf{Voice-First Interview Intelligence:} Real-time, voice-interactive simulation engine powered by Llama 3 and Deepgram Aura, providing high-fidelity technical and behavioral practice.
    \item \textbf{Semantic Match Engineering:} Advanced LLM-based semantic analysis that bypasses traditional keyword filters to identify deep technical alignment with 99\% precision.

    \item \textbf{Recruiter Intelligence \& Verification:} An elite-level CRM suite providing 'Neural Deep Scans' and automated transcript analysis to minimize hiring risk and eliminate profile fraud.
\end{itemize}

\section{Existing Systems}
The current state of recruitment technology is defined by several systemic limitations that HireSight seeks to address:
\begin{itemize}
    \item \textbf{Fragmented Recruitment Ecosystems:} Reliance on disconnected tools for sourcing, interviewing, and candidate tracking, leading to high data latency and operational silos.
    \item \textbf{Keyword-Centric ATS Filtering:} Primitive matching algorithms that focus on word frequency rather than semantic technical competence, resulting in high false-rejection rates for qualified talent.
    \item \textbf{Static \& Non-Interactive Preparation:} Traditional interview prep platforms offer only text-based banks or passive video content, failing to replicate the real-time pressure of verbal technical dialogue.
    \item \textbf{High-Friction Manual Outreach:} Networking and candidate engagement currently depend on manual, templated efforts, leading to poor response rates and 'Outreach Fatigue' in recruiters.
    \item \textbf{Surface-Level CRM Data:} Conventional CRM systems act as simple databases for contact info and resumes, lacking any mechanism to capture deep conversational or technical archetypes.
\end{itemize}

\section{Problem Statement}
\begin{itemize}

\end{itemize}

\section{System Architecture}
The project follows a modern \textbf{Full-Stack Serverless Architecture}:
\begin{itemize}
    \item \textbf{Frontend:} Next.js (App Router) with TypeScript for type safety.
    \item \textbf{Styling:} Tailwind CSS with Glassmorphism and Framer Motion for premium animations.
    \item \textbf{Backend-as-a-Service:} Supabase for PostgreSQL database, User Authentication, and File Storage (Resumes).
    \item \textbf{AI Orchestration:} Next.js API Routes acting as a middleware between the UI and AI Engines.
    \item \textbf{Dual-Engine AI Rotator:} A custom implementation to load-balance requests between multiple Groq API keys to ensure 99.9\% uptime and bypass rate limits.
\end{itemize}

\section{Key Algorithms \& Innovations}
\begin{enumerate}
    \item \textbf{Dual-Engine Load Balancing:} An algorithm that rotates API keys and models (Llama 3 70B vs 8B) based on task complexity and rate limit status.
    \item \textbf{Sequential Voice Chunking:} Logic that splits long AI responses into semantic chunks to allow seamless real-time audio playback without character limit bottlenecks.
    \item \textbf{Neural Deep Scan:} A recursive parsing algorithm that extracts technical archetypes and soft-skill metrics from raw resumes and interview transcripts.
    \item \textbf{A* Pathfinding for Career Trajectories:} A search algorithm used to calculate the most efficient path for a candidate to reach their 'Goal Role' by mapping current skill gaps as heuristic costs.
    \item \textbf{Heuristic-Based Recruiter Verdicts:} A multi-weighted heuristic algorithm that evaluates interview transcripts and resumes to generate an 'Extraction Score' and culture-fit probability.
\end{enumerate}

\section{Expected Review Questions \& Answers}

\subsection*{Q1: What is the unique selling point (USP) of HireSight?}
\textbf{Answer:} Unlike generic job boards, HireSight provides a \textbf{Voice-First} experience. Our AI doesn't just show jobs; it conducts mock interviews, generates outreach pulses, and provides recruiters with a "Neural Deep Scan" of candidates, making recruitment 10x faster.

\subsection*{Q2: How do you handle AI Rate Limits?}
\textbf{Answer:} We implemented a custom \textbf{API Rotator} in \texttt{lib/groq-client.ts}. It monitors usage across primary and secondary keys, automatically switching if one hits a limit, ensuring the "War Room" never goes silent.

\subsection*{Q3: Why did you choose Supabase over a custom Node.js backend?}
\textbf{Answer:} Speed and scalability. Supabase provides real-time database capabilities, built-in Auth, and edge functions which allowed us to focus 100\% on the AI logic and UI aesthetics rather than boilerplate server code.

\subsection*{Q4: Explain the 3D integration in the project.}
\textbf{Answer:} We used \textbf{Three.js} and \textbf{React Three Fiber} to create the "Robot Scene." This increases user engagement by giving the AI a physical "presence" during mock interviews.

\subsection*{Q5: How does the "Networking Pulse" work?}
\textbf{Answer:} It uses a prompt-engineered Llama 3 70B model to take user input (Target Company, Role, Tone) and output a strict JSON structure containing highly personalized Email and LinkedIn drafts.
