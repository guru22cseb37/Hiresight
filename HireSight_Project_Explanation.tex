\begin{tcolorbox}[colback=primary!5,colframe=primary,title=\textbf{1. Executive Summary}]
HireSight is an end-to-end, AI-powered recruitment engine designed to bridge the gap between job seekers and recruiters. By leveraging state-of-the-art Large Language Models (LLMs), Vector Databases, and Agentic Workflows, the platform automates the most tedious aspects of hiring. It provides candidates with an elite ATS-optimized resume builder while offering recruiters an autonomous sourcing dashboard backed by real-time market intelligence.
\end{tcolorbox}

\section{Core Features \& Modules}

\begin{itemize}
    \item \textbf{AI-Powered LaTeX Resume Architect:} A flagship module that dynamically generates visually stunning, single-page, ATS-optimized resumes. It utilizes LLMs to automatically rewrite user bullet points using the STAR (Situation, Task, Action, Result) methodology.
    \item \textbf{Autonomous Sourcing HUD:} A high-performance dashboard for recruiters that scrapes, analyzes, and ranks candidate profiles from across the web using AI semantic matching.
    \item \textbf{Market Intelligence Integration:} Uses automated workflows (n8n) and external APIs (RapidAPI, Perplexity) to gather and push real-time job market data directly into the platform.
    \item \textbf{ATS Scoring Engine:} An intelligent audit system that validates resumes against modern Applicant Tracking Systems (Taleo, Workday) and provides an integrity score.
\end{itemize}

\section{The Technology Stack}
HireSight is built on a highly modern, scalable architecture intended for enterprise-level performance.

\subsection{Frontend Infrastructure}
\begin{itemize}
    \item \textbf{Framework:} Next.js \& React (TypeScript) for robust, Server-Side Rendered (SSR) performance.
    \item \textbf{Styling:} TailwindCSS and Framer Motion to create a premium, "glassmorphic" UI with 98\% Lighthouse performance scores.
    \item \textbf{Code Editor:} CodeMirror for live LaTeX code editing and syntax highlighting.
\end{itemize}

\subsection{Backend \& Database Infrastructure}
\begin{itemize}
    \item \textbf{API Layer:} Next.js Route Handlers to process secure, RESTful requests.
    \item \textbf{Database \& Auth:} Supabase (PostgreSQL) handling real-time data synchronization and edge functions.
    \item \textbf{Vector Search:} pgvector (Supabase) for executing high-precision semantic similarity searches between candidate resumes and job descriptions.
\end{itemize}

\subsection{Artificial Intelligence \& Automation}
\begin{itemize}
    \item \textbf{LLM Routing Network:} Groq (Llama-3.3-70b-versatile) for lightning-fast inference, backed by Google Gemini 2.0 Flash as a robust fallback.
    \item \textbf{Workflow Automation:} n8n and Python (Selenium, BeautifulSoup) for data pipelines and web scraping.
\end{itemize}

\section{System Workflow: How It Works}
\begin{enumerate}
    \item \textbf{Data Ingestion:} The user inputs their raw career data (experience, skills). 
    \item \textbf{AI Expansion:} The API routes the data to an LLM, prompting it to expand brief descriptions into professional, keyword-rich achievements.
    \item \textbf{LaTeX Typesetting:} The AI injects this data into a strictly defined LaTeX preamble. 
    \item \textbf{Compilation:} The LaTeX source is compiled into a high-fidelity PDF and immediately previewed in the browser.
\end{enumerate}

\section{Value Proposition (Uses for Users)}

\subsection{For Job Seekers (Candidates)}
\begin{itemize}
    \item \textbf{Beat the ATS:} Guaranteed parsing by major Applicant Tracking Systems due to strict single-column PDF generation and an embedded text layer.
    \item \textbf{Time Savings:} Generates a world-class resume in seconds rather than hours of manual formatting in Word or basic web editors.
    \item \textbf{Content Elevation:} Transforms junior-sounding bullet points into senior-level, impact-driven statements automatically.
\end{itemize}

\subsection{For Recruiters}
\begin{itemize}
    \item \textbf{Precision Matching:} Semantic vector search ensures recruiters see candidates who actually possess the skills needed, bypassing keyword stuffing.
    \item \textbf{Real-Time Market Intel:} Access live data on salary trends, high-demand skills, and competitor hiring patterns.
\end{itemize}

\section{Future Scope: Web3 \& Blockchain Integration}
\begin{itemize}
    \item \textbf{Verifiable Credentials (Anti-Fraud):} The most immediate blockchain application is integrating cryptographic background checks. Instead of relying on manual verification, universities and employers can issue cryptographically signed tokens directly to a candidate's digital wallet. HireSight can instantly read this immutable "digital stamp" on the blockchain, verifying degrees and employment history with 100\% certainty in milliseconds. This entirely eliminates the need for expensive and time-consuming third-party background checks.
\end{itemize}
